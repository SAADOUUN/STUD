📖 Google Cloud Setup Instructions ▾
  1. Open Google Cloud Console.
  2. Go to APIs & Services → Library and enable Google Drive API.
  3. Under OAuth consent screen, select External and add your email.
  4. Under Test users, click + ADD USERS and enter your Gmail address (saaad.elfilali@gmail.com).
  5. Go to Credentials → Create Credentials → OAuth Client ID (select Web application).
  6. Add your authorized JavaScript origins: https://stud-2027.vercel.app and http://localhost.
  7. Paste your Client ID above and click Sign in!
